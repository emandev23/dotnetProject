  - Simplifier l'achat de livres
  - Offrir une expérience utilisateur intuitive
  - Gérer efficacement l'inventaire des livres

=== Slide 3: Caractéristiques Principales (2 min) ===
Pour les Clients:
• Parcourir le catalogue par genre
• Recherche de livres
• Gestion du panier d'achat
• Processus de commande simplifié
• Historique des commandes

Pour les Administrateurs:
• Gestion complète des livres (CRUD)
• Gestion des stocks
• Suivi des commandes
• Gestion des genres de livres

=== Slide 4: Architecture Technique (2 min) ===
• Technologies Utilisées:
  - ASP.NET Core MVC (.NET 8)
  - Entity Framework Core
  - MySQL Database
  - Bootstrap 5 pour l'interface
  - Identity pour l'authentification

• Architecture:
  - Pattern MVC
  - Repository Pattern
  - Dependency Injection
